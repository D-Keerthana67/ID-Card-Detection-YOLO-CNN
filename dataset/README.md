# Dataset

A custom ID-card dataset is required for reliable YOLO ID-card detection.

Recommended layout:

```text
dataset/
├── images/
│   ├── train/
│   └── val/
└── labels/
    ├── train/
    └── val/
```

Example YOLO class:

`0: id_card`

Do not commit real student photographs, ID-card images, personal information, or restricted data to a public repository.
